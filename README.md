# Makerspace equipment loan requests

Generated by the Software Factory POC from the `form-workflow` template.

A lightweight FastAPI app for a community makerspace: members request equipment
loans, approvers approve or reject each request with a mandatory note, and
viewers can observe everything read-only. No login — switch roles with the
role switcher at the top of every page.

## Roles (no login, cookie-based switcher)

- **Member** — submit loan requests (name, tool from a fixed list, start date,
  end date, reason).
- **Approver** — approve or reject pending requests with a required note.
- **Viewer** — read-only access to the list and request history.

## Run

```sh
pip install -r requirements-dev.txt
cp sf-banner.js app/static/sf-banner.js
uvicorn app.main:app --port 8080
```

Then open http://localhost:8080. Set `FIRESTORE_DB` to persist to Firestore;
without it the app uses an in-memory store (good for local runs and tests).

## Endpoints

- `GET /` — list all requests with status filter.
- `GET /requests/new`, `POST /requests` — submit a request (Member only).
- `GET /requests/{id}` — detail with full chronological status history.
- `POST /requests/{id}/decision` — approve/reject with a required note
  (Approver only, pending requests only).
- `POST /role` — switch the active role.
- `GET /healthz` — health check.
